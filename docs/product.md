# 首版产品范围

状态：产品边界已由用户确认；客户端方案于 2026-09-20 更新为 Web + Tailscale。

## 要解决的问题

用户离开电脑后，仍能用 iPhone Safari 连接自己的 Mac，在电脑工作目录中启动 coding agent，看到并操作其原生 TUI。首版是个人自用的私有 Web 工具，不是公开互联网服务。

## 已确认的首版能力

1. iPhone 与 Mac 不必处于同一局域网；双方联网并连接同一 Tailscale tailnet 即可访问。
2. 手机找到电脑上的工作目录，并选择本机可用的 agent。
3. 在该目录启动 agent 原生交互式 TUI，展示输出并传递输入。
4. 同一工作目录支持多个独立 agent 终端，手机能切换查看。
5. 手机锁屏、切后台、关闭网页或断网时，电脑上的 agent 继续运行；重新打开后恢复连接和终端现场。
6. 会话历史和 resume 仍以 agent 原生能力为事实源；Codex 模式可通过其官方 app-server 列出名称，并通过 `codex resume` 恢复，不建立产品聊天数据库。

`project/workspace` 只是工作目录的入口，不是需要创建、注册或关联的业务实体。

## 建议的最小使用流程

一次性准备：Mac 与 iPhone 安装 Tailscale 并登录同一 tailnet → Mac 启动 Code Remote Web 服务 → 手机打开该 Mac 的私有地址。

日常使用：打开 Safari 地址或主屏幕书签 → 选择工作目录 → 选择 agent → 进入 TUI。对话面板分开显示正在运行的终端和当前目录的 Codex 历史；前者直接重新附着，后者使用 Codex 原生名称并恢复到新的独立终端。“新建对话”会在同一目录启动新的独立 agent 终端，切换页面不会停止其他对话。

首版建议只有三个主要页面：电脑连接/前置检查、目录入口及终端列表、全屏终端。目录入口采用浏览与最近使用路径；终端交互直接使用手机键盘，不额外常驻 Esc、Tab、方向键、Ctrl 等控制键条。具体触控、键盘和滚动体验必须在真实 iPhone Safari 中试验。

终端页采用移动端 coding agent 控制台的信息层级：紧凑连接状态 → 当前工作目录/agent 上下文 → 原生 TUI 运行现场 → 独立多行指令输入区 → 项目、路径与设置入口。输入区是主要操作，必须与终端输出清楚分隔并显示可发送状态和字符数；长路径需要截断但可查看完整值。

此视觉层级不改变数据边界：页面可以展示真实连接、附着、进程退出和终端尺寸，但不能把 TUI 文本拆成产品自己的聊天、工具调用或完成状态。路径切换通过在所选 cwd 新建终端实现；模型信息仍由 agent 原生会话负责，Codex 模式只触发其 `/model` 等原生指令，不复制模型清单或伪造当前模型状态。

“离开终端”仅断开显示，“结束终端”才终止对应进程，界面必须区分。同一目录里的终端共享真实文件，首版不自动隔离文件或协调修改。

## 首版不做

- Web 客户端以外的手机交付形态。
- 自建公网 Relay、端口映射、Tailscale Funnel 或公开互联网访问。
- 为 Tailscale 再实现一套产品账号、设备配对或 VPN 管理界面。
- 多 agent 自动分工、通信、调度、合并改动或 worktree 管理。
- 产品独立的对话数据库、聊天气泡协议、跨 provider 上下文转换。
- 项目管理、任务看板、Git 操作界面、代码编辑器。
- 统一模型账号、模型转售、provider 登录向导和计费体系。
- 把已经在其他终端/桌面 App 中打开的任意会话无缝接管。
- 推送通知、手机后台实时画面常驻、云端代跑、电脑休眠唤醒。
- 多用户协作、通用远程桌面、首发 Android。

## 使用前提与工程默认

- 用户拥有 iPhone 和 Mac；电脑端暂只实现 macOS。
- 两台设备都已安装并启用 Tailscale，加入同一 tailnet，并允许对应流量。
- 电脑上的 agent 已安装且能正常运行。手机复用电脑上的运行环境和 provider 凭据。
- 电脑保持开机、可执行、不进入影响服务的睡眠状态并持续联网；关机、休眠和 Tailscale 下线不在“持续执行”保证内。
- 首版优先验证 Codex 与 Claude Code 两个 CLI，不因传输的是终端字节就宣称兼容所有 agent。
- Tailscale 只解决私网连通与设备身份。Web 服务、终端授权边界、tmux 生命周期和恢复仍由本项目负责。

## 成功标准

iPhone 使用蜂窝网络、Mac 使用另一网络，两者通过 Tailscale 连接；用户能在 Safari 中从真实目录启动 Codex 和 Claude，输入任务并看到原生执行输出，切换两个终端后各自状态保留。锁屏、关闭页面或断网期间任务继续，重新打开网页后接回原终端，不重复启动任务。

最终能否称为“跑通”，以[真实设备验收表](validation.md)为准，不以桌面浏览器截图、WebSocket 回声或静态 UI 代替。
